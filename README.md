# homebrew-tap

Homebrew casks by Oleh Fostyak.

## Lad

A keyboard layout switcher for macOS that fixes Ukrainian and English typed in the wrong layout and never touches the network. Source and details: [OlehFostyak/Lad](https://github.com/OlehFostyak/Lad).

```sh
brew install --cask olehfostyak/tap/lad
brew upgrade --cask lad
```

Lad is not notarized by Apple. On first launch, open System Settings → Privacy & Security and click "Open Anyway", then allow Lad in Accessibility.
